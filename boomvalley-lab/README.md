# BOOMVALLEY Lab

The research instrument of this edition: it reads a study declaration (`bvl-study-1`), runs the declared organization of actors (models, humans or tools) under a fixed plan and protocol, records every call, decision, World transition and memory, and seals the run into an evidence package (`MANIFEST-4.json`).

- Distribution `boomvalley` 1.0.0rc3, Python package `boomvalley_lab` (`src/boomvalley_lab/`). The earlier research instrument `src/boomvalley/` of the development repository is not part of this edition: `boomvalley_lab` does not import it.
- Commands: `bvl` (the study front end: `validate`, `check`, `run`, `package`, `verify`, `analyse`) and `boomvalley-lab`.
- Runtime dependencies: none outside the Python standard library (Python 3.11 or later).

Install and use: see `../README.md` and `../REPRODUCIBILITY.md`. The full reference is the researcher manual in `../docs/`.
